```bash

```

PowerShell:

```powershell

python score_heidi_rtt.py --input "heidi_part1_side_by_side(1).json" --generate --model roberta-base
```

`--generate` makes paid model calls for each uncached row. Translations are cached in `ai_translations_cache.json`; restart to reuse. To use AI English already generated by your app, export a JSON object keyed by alignment group ID, e.g. `{ "ch01-a001": "English translation ...", "ch01-a002": "..." }`, then use `--ai-json translations.json` instead.

To process only a part, add `--chapter 1` and/or `--limit 10`.

## Outputs

- `heidi_rtt_scored.json`: copy of the *full* input JSON, with `rtt_bertscore` nested in each scored row; never overwrites direct scores or original input.
- `heidi_rtt_scores.csv`: one row per scored alignment group.
- `ai_translations_cache.json`: cached German-to-English translations.

The row field `rtt_bertscore.f1_x100` is `100 * raw BERTScore F1`, **not a validated translation-preservation percentage**. BERTScore evaluates token similarity using contextual embeddings. It may not detect contradictions, omissions, and additions reliably enough to serve alone as a literary fidelity judge. `precision` reflects model match for AI text relative to human reference, `recall` vice versa; F1 balances both.

The score implementation compares whole passages when short. Long passages are split into sentence-boundary chunks, and all chunks are matched 1:1 using maximum-weight assignment; unmatched chunks are penalized. Since Stork can combine/split/reorder material, the *chunked* score is a heuristic and should be flagged for human review; it is **not strictly comparable to whole-passage BERTScore**. Use `chunked` to filter or report results separately.

A BERTScore score does **not** produce word-level preserved/changed/lost highlights. Use a separate clause/proposition alignment + human-validated semantic classification component for that. Also do not compare the RTT BERTScore F1 directly with a direct-assessment 76/100 unless your scales are calibrated against human judgments.

## Method recommendation

- **RTT/independent translation English-vs-English consistency:** BERTScore F1, as implemented here, is a reproducible baseline.
- **Direct German-to-English MT quality**: use reference-based COMET (`Unbabel/wmt22-comet-da`) with `src=German`, `mt=Stork English`, `ref=independent AI English` as a *supplementary metric*, not a ground-truth semantic score. COMET is trained on translation-quality judgments but is not validated automatically for your historical literary domain.
- For the *actual scientific claim* of preservation of meaning, evaluate a manually annotated sample including negation, omissions, additions, names, imagery, and reordered clauses; report agreement/correlation and uncertainty.
